# App icon & splash sources
Place here, then run `npm run assets:generate` (from client-app/):
- icon-only.png    1024x1024, opaque (app icon)
- splash.png       2732x2732, logo centered on brand navy
- splash-dark.png  2732x2732, dark-mode variant (optional)
@capacitor/assets generates every iOS/Android size into the native projects.
